# SmartScan AI — Microsoft Store listing

**Name:** SmartScan AI

**Short description:** Scan, understand and track documents.

SmartScan AI turns receipts, invoices, bills, contracts and PDFs into searchable information. Scan or import a file, extract English text, review key fields, track expenses, ask focused questions about a document and export organized results.

## Key features
- English OCR
- PDF text extraction
- Document classification
- Vendor, total, VAT/tax, reference and date extraction
- Expense categories and CSV export
- Document Q&A
- Local document history
- PDF report export

## Pricing
- Free download
- SmartScan Pro: $8.99/month
- SmartScan Pro Annual: $59.99/year

SmartScan is an assistance tool. OCR and automated extraction may contain errors. Verify important financial, legal, tax, accounting or contractual information against the original document.
